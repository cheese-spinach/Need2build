# 抖音单平台需求验证通道（巨量算数 · 手动填写版）

## 这条通道解决什么

原管线把热榜当需求，导致「0 条需求表达 → 8 个机会、最高 82 分」这种结果。
本通道是独立于 `js/pipeline.js` 的一条单平台链，用来先跑通少量真实案例，验证判定逻辑本身是否成立。

三层结构（2026-10-05 实测后调整）：

1. **话题层**：抖音热榜。**实测结论：派生不出需求**——"旗袍"20 个关联词里 0 个需求形状，
   全是内容实体（田曦薇、女明星、珠宝）。热榜保留为观察项与负对照，不再是种子源。
2. **需求层**：赛道种子词 → 抖音指数「关联分析」→ 带需求形状的关联词。
   换种子词就换出一批需求，这才是发现机制。
3. **机会层**：需求形状关联词 ≥ 2 个，才允许成卡；卡内按形状聚成「需求方向」。

种子词目前人工维护（14 个赛道词跑出 13 张卡）。热榜的正确位置是给种子表提示
「哪个赛道在升温」，而不是直接派生需求。

## 使用步骤

### 1. 生成待填表

```bash
node scripts/topic-radar.mjs seed --limit 12
```

从 `js/live-data.json` 的抖音热榜取话题，写入 `data/douyin-topic-sheet.json`。
重复执行只会追加新话题，不会覆盖你已经填好的内容。

> 正式实验建议换成巨量算数自己的热点榜：把榜单里的标题手工加进 `topics` 数组即可，
> 60s 热榜与巨量算数口径不同，两者热度数字不能混用。

### 2. 去巨量算数补三项

对每个话题，在巨量算数「关键词分析」里输入一个代表性关键词，回填到对应条目：

| 字段 | 含义 |
| --- | --- |
| `keyword` | 你输入的关键词 |
| `searchIndex` | 该词搜索指数 |
| `contentIndex` | 该词内容指数（可选） |
| `relatedWords` | 关联词，建议 10–20 个 |

`relatedWords` 支持三种写法，怎么省事怎么填：

```json
"relatedWords": ["增程suv推荐", "增程suv怎么充电"]
```

```json
"relatedWords": "增程suv推荐, 增程suv怎么充电"
```

```json
"relatedWords": [{ "word": "增程suv推荐", "searchIndex": 1100 }]
```

查不到的字段就留 `null`，不要猜数字。

数值字段名可以按来源口径取：抖音指数的关联分析给的是**相关性(0-100)**，用 `correlation`；
其他来源给的是**搜索指数**，用 `searchIndex`。两者都会被识别。
表头的 `metricLabel` / `subjectMetricLabel` 只影响报告里的显示文案。

每条 topic 还可以带 `origin`：`hot-list`（来自热榜）或 `control`（人工挑的对照词）。
对照组用来回答一个关键问题——**同一个工具，换成需求型词还能不能出需求形状**。

### 3. 出报告

```bash
node scripts/topic-radar.mjs report
```

终端会打印待查清单、机会卡和未过门禁的话题；完整结果写入 `data/douyin-opportunities.json`。

## 需求形状

只有命中这些形状的关联词才算「需求意图」，其余一律视为内容噪音：

| 形状 | 命中示例 |
| --- | --- |
| 选型决策 | 推荐 / 哪个好 / 怎么选 / 对比 / 值不值 |
| 工具诉求 | app / 软件 / 工具 / 小程序 / 模板 |
| 求解教程 | 怎么 / 如何 / 教程 / 攻略 / 方法 |
| 成本门槛 | 多少钱 / 价格 / 免费 / 成本 |
| 替代平替 | 平替 / 替代 / 类似 |
| 验证口碑 | 靠谱吗 / 有用吗 / 测评 / 避坑 |
| 获取安装 | 下载 / 安装 / 哪里能 |

## 为什么 v1 没有评分

原来的 82 分是「热度条数 × 权重」算出来的，热度越高越像机会，方向正好反了。
在阈值校准之前，这条通道只输出可核对的原始证据（需求词、形状、指数），
等第一批 3–5 个案例跑完、看清指数量级之后，再决定是否引入评分。

## 已知缺口

搜索指数证明的是**需求强度**，不是**需求原话**。
每张卡的 `proofLinks` 给出了对应的抖音搜索链接，需要人工进去取 3 条求助 / 评论原文，
才算凑齐「可验证」的完整证据。这一步目前不能省。
